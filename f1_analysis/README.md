## 🚙🏁 Overview

### 1. __f1_data_stat_project__

Comprehensive F1 dataset analysis covering 2001-2024 seasons

__Tech Used:__

- __Data Processing:__ pandas, numpy
- __Visualization:__ matplotlib, seaborn
- __Statistical Analysis:__ scipy (hypothesis testing, confidence intervals)
- __Machine Learning:__ scikit-learn (Random Forest), XGBoost
- __Statistics and Machine Learning:__ scipy, scikit-learn
- __Data Source:__ Kaggle F1 Dataset (1950-2024)
